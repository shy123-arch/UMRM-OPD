## 解读

1. **"最后一层"本身没有问题，反而略好**：冻结原版只取最后一层，比 4 层混合更好（D1 显著）。之前我根据"学出来的层权重里最后一层只有 0.16"推断最后一层最不适合，这个推断错了：层权重反映的是 HumanML3D 预训练的目标，与下游效果不是一回事。不过 oracle 输入下没有这个优势，可能的解释是最后一层对 VLM 写出来的、带噪声的描述更稳健；也可能只是噪声。这是单次运行，结论要复现后才能确定。
2. **用户原设想的两个附加要素都没有带来增益**：编码器换成 SFT 学生（D2，方向为负），以及让最后一层带上视频语境（D3，+0.011）。这与之前视觉分支 B 的结论一致：学生"看视频时的语义"相对它写出的文字，没有给动作头提供可学的额外信息。V36 的预训练只能用"学生只读文字"的特征，存在分布偏移，这是一个可能的原因（见 README §4）。
3. **建议**：动作头的条件接口改用"冻结原版 + 最后一层"（A36），作为后续的默认；下一版先登记再复现一次 D1。
