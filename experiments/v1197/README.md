## 2. 事先登记（2026-10-16 00:45 CST 写入，早于本版任何训练和生成）

### 2.1 设置
- **SFT**（学生 / 教师 v2）：Qwen3-VL-4B，LoRA r16（36 层 × 7 个线性层），lr 1e-4，3 个 epoch，accum 8；按 VAL 每 token NLL 最低选 epoch。教师 v2 的 prompt = PROMPT + v1 运动学提示 + 若有 mental_reasoning 则追加"我的内心推理"。
- **动作头**：从 v860 的 `head_pre/best.pt`（HumanML3D 预训练）初始化，在 v1197 TRAIN 上微调；3000 步，每 100 步在 VAL 上算一次（mask CE + res CE），取最低点；lr 1e-4，warmup 200。三个变体：
  - `A_cap`：截断目标，只有文本接口 A；
  - `A_full`：完整事件目标，只有文本接口 A；
  - `AB_full`：完整事件目标，接口 A + 视觉残差 B。
- **视觉残差 B**：
  - 编码器 = 冻结的 v1197 SFT 学生（Qwen3-VL-4B + 选中的 LoRA 合并）。输入是视频 + PROMPT + 回答文本做教师强制：训练用真值目标，评测用被评测的预测原文。
  - 取第 9/18/27/36 层两类位置的隐状态：①视频 token 按时间组做平均池化（8 个）；②`<exec>` 行的 token。
  - 结构与 A 的适配器相同，另加类型嵌入。输出以**逐通道、零初始化的门**加到 A 的（全局向量，16 个记忆槽）上，所以训练起点与 `A_full` 完全等价。
  - OPD 学生的预测也用同一个 SFT 学生编码器，保证 B 的输入分布不随 OPD 改变。
- **OPD v2**：
  - 教师 = SFT 教师 v2，冻结；学生 = v1197 SFT 学生。
  - 只在**有 mental_reasoning 的 TRAIN 条目（430 条）**上训练。没有"做什么"信息的条目只剩运动学提示，v860 已经证明那样会导致塌缩。
  - 每个视频采 K=4 个样本，温度 1；lr 5e-5；accum 4；2 个 epoch；取最后一个 epoch。
  - 损失 = **0.5·反向 KL + 0.5·前向 KL**，按 token 在整词表上精确计算，只在 `<reaction>` 和 `<exec>` 行的 token 上算（`<plan>` 行和结束符不算）。
  - 训练期间不调用生成器。

### 2.2 统计
VAL 125 条（主要）；另报 v860-VAL 96 条子集和有 mental_reasoning 的 VAL 76 条子集。Kimodo 臂 3 个种子，自有头 3 个样本。按来源做 cluster bootstrap 95% CI + Wilcoxon，未做多重比较校正。主语义指标：R@10、t2m 相似度；同类 R@3 与中位排名为辅。

### 2.3 门
- **G-V（视觉残差是否有用，主问题 3）**：SFT 学生 greedy 预测 → 自有头。`AB_full` 相对 `A_full` 的 R@10 或 t2m 的 CI 下界 > 0 → 通过。附加对照：`AB_full` 用"错配视频"的 B 特征（VAL 内按 ⌊N/6⌋ 位移）时，R@10 或 t2m 应显著下降（差的 CI 上界 < 0），证明 B 用的是逐条视觉信息。同时报告门的大小，以及 oracle 文本下的诊断结果。
- **E1-确认**：SFT 预测 → 自有头，`A_full` 相对 `A_cap` 的 R@10 或 t2m 的 CI 下界 > 0（这是 v860 探索性 E1 的确认性检验）。
- **G-T2（教师 v2 是否带来"做什么"的信息，诊断用）**：在 76 条有 mental_reasoning 的 VAL 上，教师 v2（带 z）的 greedy 相对学生 greedy，exec 与 gt3p 的 TMR 文本余弦均值高 ≥ 0.05；且在反应/exec 区段上 KL(带 z) ≥ 1.5 × KL(不带 z)。按用户要求，无论 G-T2 是否通过都训练 OPD v2，G-T2 只用来解读结果。
- **G4-v2（OPD v2 是否有效）**：主臂 Kimodo-TPH，VAL 125。OPD v2 最终 epoch 相对 SFT 学生，R@10 或 t2m 的 CI 下界 > 0；并且 direction 和 duration 计划分布的 TV 距离都不比 SFT 恶化超过 0.1。第二读数：自有头 `A_full` 臂。CI 跨 0 但方向一致，记为"未证实"。
- **探索性（不是门）**：v1197 SFT 相对 v860 SFT（在 v860-VAL 96 条上，Kimodo-TPH），用来看数据扩到 1197 带来的变化。
