# vt_lastlayer_v1197aug — "VLM 最后一层输出单独作为动作头条件"的干净检验

用户 2026-10-16 21:25 要求：干净地检验"LLM 最后一层 decoder 的输出单独作为动作头的条件语义"。
以前只有一次相关尝试（cliponly_v1，09-18）：冻结的 Qwen2.5-VL-3B 零样本、对全部 token 求平均、随机初始化的回归头，混杂因素太多。这几天的主线里，最后一层只出现在 4 层混合中，从没单独用过。

## 1. 设计：一次只改一个因素

模型统一用路线主线的 Qwen3-VL-4B（Qwen2.5-VL 没有 4B 版本；主线的 SFT 学生是 Qwen3-VL-4B）。数据、划分、动作头结构、预训练与微调流程、生成和评测完全沿用 v1197aug。

| 臂 | 编码器 | 输入语境 | 取哪一层 | 取哪些 token | 动作头预训练（HumanML3D） |
|---|---|---|---|---|---|
| **A4**（参照 = 现有接口 A） | 冻结原版 4B | 只有 `<exec>` 文字 | 第 9/18/27/36 层，学一组层权重 | exec 描述的 token | 已有 `vt_head_opd_v860/runs/head_pre`（同协议） |
| **A36** | 冻结原版 4B | 只有 `<exec>` 文字 | **只取第 36 层（最后一层）** | 同上 | 新训 `head_pre_A36` |
| **S36** | **SFT 学生**（aug epoch1，LoRA 合并） | 只有 `<exec>` 文字 | 只取第 36 层 | 同上 | 新训 `head_pre_S36`（HumanML3D 描述也用学生编码） |
| **V36**（用户设想的原样） | SFT 学生 | **视频 + 指令 + 学生自己写的回答**（训练时用真值回答做 teacher forcing） | 只取第 36 层 | `<exec>` 那一行的 token | 用 `head_pre_S36` 初始化（HumanML3D 没有视频，这是唯一可行的预训练） |

- 四个臂都只用一路条件：只有适配器 A，没有视觉分支 B。适配器结构相同：LayerNorm → MLP 降到 512 维 → 16 个查询槽做注意力池化 + 1 个全局平均向量。只取一层时，层权重退化为 1。
- 所有特征都用"本行的 exec token"，与接口 A 的定义一致，不对视频 token 求平均（cliponly_v1 那种做法会让几百个视觉 token 稀释语义）。
- V36 在推理时用的，是学生生成回答那一刻的最后一层隐状态（对它自己的 greedy 回答做 teacher forcing 重算，因果模型下与生成时等价）。
- 依次比较 A4→A36→S36→V36，三步分别隔离了"层""SFT 权重""视频语境"三个因素。

## 2. 流程（与 v1197aug 相同的超参）

1. 学生编码的文字特征（`textenc.py --adapter <SFT 学生> --prefix stu_`）：HumanML3D 全部描述，v1197 TRAIN/VAL 的 gt3p，VAL 预测（`sft_student_greedy`），VAL oracle。
2. 动作头预训练：`head.py pretrain --layers 36 [--text-prefix stu_]`，6 万步，每 2000 步看一次 HumanML3D val CE，取最低点。seed 3407，与 head_pre 相同。
3. HumanML3D 自检：固定的 1024 条测试子集，TMR R@1/2/3，A4/A36/S36 都在本目录用同一份代码重跑。
4. PICO 微调（v1197aug TRAIN 1652，完整事件目标）：3000 步，每 100 步看一次 VAL CE，取最低点；lr 1e-4，warmup 200。A4 也在本目录用同一份代码重训一次，作为代码一致性检查，应与 aug 的 head_A_full 接近。
5. 生成与评测：VAL 125 条，输入是 SFT 学生的 greedy 预测（`sft_student_greedy`），每条 3 个样本；独立评测器（官方 HumanML3D TMR + 几何）。

## 3. 事先登记的比较（2026-10-16 21:40 CST 写入，早于本目录的任何训练）

统计方法：按来源做 cluster bootstrap 求 95% CI，配 Wilcoxon，未做多重比较校正。主指标 R@10，次指标 t2m 相似度。

- **P1（主问题）**：V36 相对 A4，在 SFT 预测上。CI 下界 > 0 → V36 更好；CI 上界 < 0 → V36 更差；否则 → 差异不显著（"不比现有接口好，也没证明更差"）。
- **分解**：D1 = A36 − A4（只换层），D2 = S36 − A36（编码器换成 SFT 学生），D3 = V36 − S36（加上视频语境）。判定规则同 P1。
- **合理性检查**：每个臂相对训练集平均动作（`eval_base_train_mean`），R@10 的 CI 下界 > 0，说明确实学到了东西。
- **HumanML3D 自检**（描述性，不设门）：A36 和 S36 的 R@3，与 A4 比较。
- **探索性**：各臂在 oracle 输入下的结果（文本臂用 gt3p，V36 用真值回答在视频语境下的隐状态）。

## 4. 已知局限

- V36 的预训练只能用"学生只读文字"的特征，微调时才换成视频语境的特征，存在分布偏移。这是"HumanML3D 没有视频"决定的；如果 V36 不如 S36，偏移是可能原因之一。
- VAL 只有 125 条 / 34 个来源。
