# vt_head_opd_v1197 结果（2026-10-16）

**范围**：v1197 冻结数据；划分继承自 v860。所有结论来自 **VAL 125 条 / 34 个来源**（随机 R@10 = 0.080）。v860 的 TEST（182 条）和新来源封存块（50 条）都未读取。门和设计在训练前写入 README §2（00:45 CST）。按来源做 cluster bootstrap 95% CI + Wilcoxon；未做多重比较校正；每项只训练了一次。

## 0. 一页结论

1. **v1197 数据补齐（目标 1）**：
   - 337 条新数据：英文反应 124 条用上传者原文，213 条由 Qwen3-8B 翻译；v860 中 33 条"英文原文实为中文"的条目一并重译。
   - 第三人称描述（gt3p）用路线 6 的提示词改写 370 条。发现 46% 有"超长或凭空添加步数"的幻觉（路线 6 的 v860 改写同样有约 37%），用严格提示词重写，再修复 14 条漏掉走/跑的，最终 0 条不过门。
   - 计划标签由动捕自动提取；生成了截断版和完整事件版两份动作目标。
   - 划分继承 v860：TRAIN 840 / VAL 125 / 封存 50 / TEST 182 不动。
   - 24 条影视短片：9 条留在 TRAIN 训练，15 条在 TEST 的从评测中排除。
2. **重跑 SFT 和动作头（目标 2）**：
   - SFT 学生：格式 125/125，计划准确率 0.611；时长预测不再塌成单值。
   - 4B SFT → 自有头（完整事件）R@10 0.261，相对训练集平均动作 +0.181，CI [+0.068, +0.293]；t2m 比 Kimodo-TPH 高 +0.039，CI [+0.003, +0.071]。
   - **E1 完整事件的确认性检验未通过**：相对截断版 R@10 +0.032，CI [−0.021, +0.078]。方向与 v860 一致，但证据不足。
3. **视觉语义残差（目标 3）：G-V 不通过，而且 B 分支没有在用逐条的视频信息。**
   - 预登记版：门在选模点几乎没打开（平均绝对值 0.0007）；R@10 −0.013，CI [−0.039, +0.009]。
   - 探索性冻结主干版：门打开到 0.04，但 R@10 差 0.000，CI [−0.042, +0.040]。
   - 两者换成错配视频都不变差。
   - 结论：在当前数据规模下，SFT 学生"带视频语境的隐状态"相对它写出的文本，没有给动作头可学的额外信息。你原设想中"VLM 最后一层的视觉语义直接驱动动作头"的增益，这次没有被观察到。
4. **OPD v2（目标 4）**：
   - **G-T2 通过，而且幅度很大**：在有 mental_reasoning 的 VAL 76 条上，教师 v2 的 exec–gt3p 文本余弦 0.467 vs 学生 0.272（+0.194），反应余弦 +0.135；KL 带 z / 不带 z = 3.14 倍。v860 的纯运动学教师反应余弦为 −0.015，这次教师真正掌握了"做什么"。
   - **G4-v2 不通过**：主臂 Kimodo-TPH R@10 +0.016，CI [−0.042, +0.075]；t2m +0.001。静止率显著下降 3.2 个百分点。计划分布不再塌缩（方向 TV 只 +0.04）。
   - 自有头臂方向为正但未证实：R@10 +0.048，CI [−0.007, +0.113]；同类 R@3 +0.075，CI [+0.005, +0.145]。
   - 教师语义上限：用到真值时经自有头 R@10 0.413，学生只学到很小一部分。详见 §4。

## 4. OPD v2（目标 4）

**设置**（预登记）：
- 只在有 mental_reasoning 的 TRAIN 430 条上训练；K=4，温度 1，2 个 epoch，lr 5e-5。
- 损失 = 0.5·反向 KL + 0.5·前向 KL，只在 `<reaction>` 和 `<exec>` 两行计算。
- 共训练 216 步，约 3.5 小时（GPU 1 与他人共享）。
- KL 从约 0.23 降到约 0.16–0.19；学生熵约 1.3–1.5，稳定；采样格式 100% 合格。

**G-T2（教师 v2 是否带来"做什么"）：通过。** 见 §0 第 4 条。不同执行器上教师的语义上限：

| 教师 v2 + z（用到真值，不可部署） | R@10 | t2m |
|---|---|---|
| → Kimodo TPH | 0.261（学生 0.229） | 0.169（学生 0.138） |
| → 自有头 A（完整事件） | **0.413**（学生 0.261） | 0.259（学生 0.177） |

教师的文本质量提升很大，但经 Kimodo 只体现出很小的一部分（R@10 +0.032，CI 跨 0）。自有头能把更多文本层面的提升转成动作语义。

**G4-v2：不通过（主臂语义无提升）。** 计划分布没有塌缩，自有头臂方向为正但未证实。

- **没有塌缩**：方向分布 TV 0.30 → 0.34（+0.04），时长 TV 0.10 → 0.19（+0.09），都在 0.1 的容忍线内；计划准确率 −0.006，不显著。v860 OPD v1 的方向 TV 恶化了 0.18，所以"计划行不算 KL + 混入前向 KL"确实消除了向众数的塌缩。
- **epoch 1（探索性）略差**：Kimodo-TPH R@10 −0.032；没有 mental_reasoning 的条目上下降更明显，exec 平均长度从 10.4 词升到 12.2 词。epoch 2 回升。
- **自有头 A+B 的显著结果只算探索性**：不是预登记臂，且这里做了很多次比较。
- **与 v860 OPD v1 对比**：v1 的计划准确率上升（+0.048）来自塌缩，语义持平；v2 的计划不变，语义在自有头上方向为正，但仍未达到预登记的标准。
- **数据规模（探索性）**：在 v860-VAL 中 gt3p 没改过的 79 条上，v1197 SFT 相对 v860 SFT 的 Kimodo-TPH t2m 为 −0.019，CI [−0.043, +0.010]：数据扩到 1197 没有带来提升。新增数据以 B/D 类为主。

**解读**：
- 这一次教师确实"更懂做什么"：用到真值时，经自有头 R@10 从 0.261 到 0.413。
- 但蒸馏只把其中一小部分转给了只看视频的学生，经自有头约 +0.05，不显著；经 Kimodo 几乎为 0。
- 瓶颈仍然是"从反应前视频推断反应"本身：mental_reasoning 里的信息大多在视频里看不到。

**下一步可选**：
1. 用 1.5k–3k 数据重跑，同时补充数据也需要 mental_reasoning（或用反应后画面覆盖这部分）；
2. 增加 OPD 的 epoch，或把 K 从 4 提到 8（当前 KL 下降很慢）；
3. 把"自有头 A+B"作为下一版事先登记的主执行器，独立重测，以确认 +0.077 是否可复现。
